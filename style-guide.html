Style Guide & Design System

Esta página reúne as decisões visuais do projeto Sem Limites. O Style Guide (cores, tipografia, espaçamento) define a aparência; o Design System define os componentes reutilizáveis construídos com essas regras. As cores, as fontes e os pesos estão em variáveis CSS no :root do arquivo css/estilo.css, então mudar um valor ali muda o site inteiro de uma vez.

1. Cores

Paleta neutra de base, para que as fotos sejam o ponto de cor da página. O terracota aparece só em detalhes: links, ícones e estados de hover.

Regra de uso: fundo claro com texto escuro, ou fundo escuro com texto branco. O terracota nunca é usado como fundo de bloco grande. Aparece só em textos curtos, ícones e botões em hover.

2. Tipografia

Duas fontes do Google Fonts. Playfair Display (serifada) nos títulos, sempre com uma palavra em itálico para dar ritmo. Inter (sem serifa) em todo o resto, porque é mais legível em texto corrido e em telas pequenas.
